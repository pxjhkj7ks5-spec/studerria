# Narada Druk owner bot

## Текст для маркетплейсів

Команда `/marketplace` (також підтримується `/repost`) доступна лише дозволеним власникам у налаштованому owner-чаті.

1. Надішліть `/marketplace` і виберіть один із десяти останніх опублікованих товарів.
2. Якщо для товару збережено точний публічний допис Narada Print, бот одразу поверне готовий текст.
3. Якщо посилання ще немає, надішліть його у форматі `https://t.me/naradaprint/123`.
4. Для старого допису також можна одразу надіслати `/marketplace https://t.me/naradaprint/123`, а потім вибрати відповідний товар.

Бот приймає лише публічні посилання каналу з `TELEGRAM_CHANNEL_USERNAME` або `TELEGRAM_CHANNEL_URL`. Посилання на приватні канали, інші канали чи дописи без числового `message_id` відхиляються. Bot API не дає перелічувати довільну історію каналу, тому для старих дописів без збережених метаданих власник має один раз вставити точне посилання вручну.

Для нових товарів, опублікованих через `/makerworld`, бот автоматично зберігає `message_id` та канонічне посилання після успішної публікації. Публічний формат самого канального допису при цьому не змінюється.

Результат містить назву, короткий Telegram-опис, актуальну ціну, нейтральний рядок про друк і фінальне слово **ЗАМОВИТИ**, що веде на оригінальний допис. Посилання на сайт і окремий футер каналу до копії не додаються.
