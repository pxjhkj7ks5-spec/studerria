# Narada Druk owner bot

## Ручне замовлення

Команда `/manual` створює замовлення від імені власника в адміністраторському чаті. Після даних клієнта виберіть «Товар із каталогу» й натискайте потрібні позиції: кожне натискання додає одну одиницю, а вибір зберігається під час переходу між сторінками каталогу. Кнопка «Готово» відкриває підсумок, де можна прибрати по одній одиниці, повернутися до каталогу або створити замовлення.

## Текст для маркетплейсів

Команда `/marketplace` (також підтримується `/repost`) доступна лише дозволеним власникам у налаштованому owner-чаті.

1. Надішліть `/marketplace` і виберіть опублікований товар. Кнопки «Давніші →» та «← Новіші» перегортають увесь каталог по десять товарів. Для пошуку надішліть назву товару; кнопка «Усі товари» скидає пошук.
2. Якщо для товару збережено точний публічний допис Narada Print, бот одразу поверне готовий текст.
3. Якщо посилання ще немає, надішліть його у форматі `https://t.me/naradaprint/123`.
4. Для старого допису також можна одразу надіслати `/marketplace https://t.me/naradaprint/123`, а потім вибрати відповідний товар.

Бот приймає лише публічні посилання каналу з `TELEGRAM_CHANNEL_USERNAME` або `TELEGRAM_CHANNEL_URL`. Посилання на приватні канали, інші канали чи дописи без числового `message_id` відхиляються. Bot API не дає перелічувати довільну історію каналу, тому для старих дописів без збережених метаданих власник має один раз вставити точне посилання вручну.

Для нових товарів, опублікованих через `/makerworld`, бот автоматично зберігає `message_id` та канонічне посилання після успішної публікації. Публічний формат самого канального допису при цьому не змінюється.

Результат містить назву, короткий Telegram-опис, актуальну ціну, нейтральний рядок про друк і фінальне слово **ЗАМОВИТИ**, що веде на оригінальний допис. Посилання на сайт і окремий футер каналу до копії не додаються.

## Редагування замовлень

У `/orders` відкрийте замовлення й натисніть «Редагувати замовлення». Оберіть поле та надішліть нове значення. Доступні дані клієнта, доставка, оплата, коментар клієнта та кількість кожної позиції (1–20). Для ручних позицій доступні також назва та погоджена ціна. «-» очищає необовʼязкове поле; `/cancel` скасовує введення.

Зміни зберігаються в наявному замовленні та його історії. Кількість каталожного товару перераховується за актуальною ціною каталогу, підсумок — зі збереженими умовами промокоду. Ціну каталожного товару вручну змінити не можна. Якщо замовлення змінилося під час введення, відкрийте редагування повторно. Введення приймається лише від власника, який обрав поле.
