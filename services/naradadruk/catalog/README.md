# Каталог Narada Druk

Каталог зібрано з публічного Telegram-каналу
[`@naradaprint`](https://t.me/naradaprint) і підготовлено для подальшого
імпорту на сайт.

## Файли

- `products.json` — нормалізований каталог, узгоджений зі структурою
  `Category`, `Product`, `ProductVariant` і `ProductImage` у Prisma.
- `products.csv` — плоский експорт для перегляду й редагування у табличному
  редакторі.
- `telegram-posts.json` — вихідні публікації, посилання та метадані.
- `images/telegram/` — локальні копії фотографій, які не залежать від строку
  дії Telegram CDN-посилань.

## Оновлення

У каталозі сервісу:

```bash
npm run catalog:refresh
```

Команда повторно зчитує канал, завантажує фото й перебудовує JSON та CSV.
Скрипт перевіряє, що кожний новий допис із ціною має явне зіставлення у
`scripts/build-telegram-catalog.mjs`; якщо в каналі з’явився новий товар,
збірка каталогу зупиниться з переліком необроблених дописів.

## Імпорт на сайт

`products.json` зберігає:

- категорії;
- назву, slug, описи, ціну й порядок товару;
- цінові варіанти;
- локальні шляхи до фото;
- посилання на вихідний допис і його початковий текст.

Перед імпортом варто лише переглянути назви, категорії та актуальність цін.
Сирі Telegram-публікації залишаються поруч для швидкої звірки.

Під час запуску Docker-сервіс перевіряє hash `products.json` і автоматично
імпортує змінений каталог у SQLite. Повторний запуск із незмінним файлом не
перезаписує базу.
